Is GTA VI playable on PC yet?

No.

Four public projects and one private build have reached stage 6 of 7, in-game. None is playable yet. The best picture is lit only where sunlight falls, at 2 to 4 frames a second.

Best guess for playable: about 6½ days, on the afternoon of Tue 1 Dec.

Seventeen projects are trying to run the Xbox Series build of GTA VI on a PC. This page reads their public repositories and reports how far each says it has got. Last checked 19:30 UTC on Tue 24 Nov.

6 In-game Five projects, at the front

  1. Position 1

    victory-gta6

    Fork of VIctory aimed at a correct, playable picture

    Plays the opening cutscene lit and in order, then renders the first gameplay scene with characters, textures, sky and a sunlit exterior; the HUD, pause menu and gamepad work. Anything out of direct sunlight is black because ray-traced light does not run yet, and the world runs at 2 to 4 frames a second. Its newest commits lose the GPU device soon after start on the test machine.

    Source: project README, tested on one RTX 4070. Entry changed 19:30 UTC, Tue 24 Nov. Last commit 19:30 UTC, Tue 24 Nov.

  2. Position 2

    AnyXboxX

    Xbox Series emulator focused on this one game, built on VIctory

    Its README says the world runs with a controllable character but a black 3D picture, at 2.4 to 3.2 frames a second. In an open pull request (#167, not merged) the maintainer reports switching to the victory-gta6 fork and playing about 13 minutes in the starting area at about 4 frames a second, moving the character and meeting the first characters, before the GPU device was lost.

    Source: project README; open PR #167, observed by the maintainer on an RTX 4070 SUPER. Entry changed 19:30 UTC, Tue 24 Nov. Last commit 17:19 UTC, Tue 24 Nov.

  3. Position 3

    VIctory

    Runs the game's Xbox code natively on Windows

    The upstream code base that victory-gta6 and AnyXboxX build on. Its README boots the game, runs the menus at 30 fps and loads into the world in about 50 seconds, where the first mission's title card renders but the scene after it stays dark, at 0.5 to 1.8 seconds a frame. Entering the world can hang a real graphics card.

    Source: project README (status dated 23 Nov), tested on one RX 6700 XT. Entry changed 19:30 UTC, Tue 24 Nov. Last commit 09:53 UTC, Tue 24 Nov.

  4. Position 4=

    Palmwave

    Xbox Series to Windows layer with its own shader path

    The first mission starts and part of the world's geometry is drawn, such as poles, power lines and fences, but about 91% of the depth buffer is empty and the picture is one flat colour because nothing is lit yet. A world frame takes about 10 seconds. The runs use an unmerged branch and ten byte patches to the game, which switch off its hang detector and several heavy render passes.

    Source: project README; a modified run on an unmerged branch, RTX 5080. Entry changed 19:30 UTC, Tue 24 Nov. Last commit 16:22 UTC, Tue 24 Nov.

  5. Position 4=

    CGBJ Unconfirmed

    Private build, reportedly based on VIctory. No public code

    Press coverage has described a private build in the game world with a player walking, unlit and very slow. Nobody outside the group can test it, and this page has found no first-hand source, so it is listed last among the stage 6 projects.

    Source: press reports only; not confirmed by this page. Entry changed 19:30 UTC, Tue 24 Nov. No public code.

5 Recognisable picture Eight projects, 1 stage behind the front

  1. Position 6

    five-star-recomp

    Native recompilation of the Xbox Series release

    Starts, shows the logo, intro art and first-run screens, loads story mode and reaches the story intro's title card, then stops. All 25,908 of the game's shader programs translate and compile.

    Source: project README and wiki status page. Entry changed 18:20 UTC, Tue 24 Nov. Last commit 19:25 UTC, Tue 24 Nov.

  2. Position 7=

    XCL

    General Xbox Series to Windows compatibility layer, in the spirit of Proton

    Starts the game in about four seconds and holds a steady 30 fps through its menus and on to the settings screens without crashing. Gameplay is not reached yet. All 26,698 of the game's GPU programs translate.

    Source: project README (it calls the game "a newer retail game"). Entry changed 18:20 UTC, Tue 24 Nov. Last commit 18:29 UTC, Tue 24 Nov.

  3. Position 7=

    OpenScarlett (Community Edition)

    Xbox Series runtime for Windows and Linux

    Runs the first-boot settings, legal and start screens at 30 fps and plays the 4K intro movie with sound, then stops while it streams in the scene behind the menus. About nine in ten of the game's shaders translate.

    Source: project README (it calls the game "a newer retail game"). Entry changed 18:20 UTC, Tue 24 Nov. Last commit 19:14 UTC, Tue 24 Nov.

  4. Position 7=

    PercyScarlett

    Xbox Series runtime; already runs Minecraft's Series build in-world

    Renders the account picker, plays the game's 4K video and walks through the full first-run setup with a gamepad, saving settings and starting to stream the world.

    Source: project README, which refers to the game by a nickname. Entry changed 18:20 UTC, Tue 24 Nov. Last commit 09:38 UTC, Tue 24 Nov.

  5. Position 10

    Xbox2Windows

    Static recompiler and runtime for Xbox Series executables

    A modified diagnostic build, which skips failed checks automatically, played the intro, showed readable setup text and reached loading on an RTX 4060 laptop. Starting the original executable is not yet shown.

    Source: project README and its progress issue. Entry changed 18:20 UTC, Tue 24 Nov. Last commit 19:29 UTC, Tue 24 Nov.

  6. Position 11=

    TuxBox

    Runs Xbox Series games on Linux through Proton

    Shows the game's player-selection prompt at 3840 by 2160 on stock Proton Experimental. It is the furthest Linux-first project.

    Source: project README. Entry changed 18:20 UTC, Tue 24 Nov. Last commit 17:30 UTC, Tue 24 Nov.

  7. Position 11=

    g6shim

    Stand-in system libraries for the Series release

    Starts the game, opens all its archives and renders its screens up to the account picker at about 12 frames a second. Next it needs an offline user, then the main menu. About 84% of the game's shaders translate.

    Source: project README (it names the game by its title ID, 7952987A). Entry changed 19:30 UTC, Tue 24 Nov. Last commit 19:29 UTC, Tue 24 Nov.

  8. Position 13

    GTA6-BootTest

    Boot harness with stand-in libraries and its own shader translator

    Boots, streams its archives, runs the frame loop and draws its first interface screen, the start-screen prompt bar, through translated shaders. Screens after that go black again.

    Source: project README. Entry changed 18:20 UTC, Tue 24 Nov. Last commit 01:09 UTC, Tue 24 Nov.

    Its README reports more than 360 crash-free 4K frames from a retail title it does not name. A commit on 24 Nov says the game now finishes all 249 of its start-up tasks and runs its interface loop at 30 fps, but neither source says a screen of the game has been seen, so it stays at stage 4.

    Source: project README and commit ef763eb. Entry changed 19:30 UTC, Tue 24 Nov. Last commit 06:28 UTC, Tue 24 Nov.

  2. Position 15

    Holy-Interoperability

    Compatibility layer for Xbox Series games

    A retail title it does not name loads, creates its graphics device, streams its start-up data and presents its first frame after about 30 seconds, then stops in its own start-up code. The README says nothing it draws has been seen yet.

    Source: project README. Entry changed 19:30 UTC, Tue 24 Nov. Last commit 03:20 UTC, Tue 24 Nov.

  3. Position 16

    xbox-emulator

    General Xbox Series runtime, a continuation of TomBox

    A contributor reports running the game on an experimental branch for six minutes, with at least 900 frames presented at up to about 5 a second. Every frame sampled was fully black, so no screen of the game has been seen. The project's own README still lists the game as not run.

    Source: open PR #371 by a contributor, not merged; GTX 1070 Ti. Entry changed 19:30 UTC, Tue 24 Nov. Last commit 11:58 UTC, Mon 23 Nov.

3 Graphics device One project, 3 stages behind the front

  1. Position 17

    palmetto

    Solo clean-room runtime, started from Leonida's work

    Boots and runs its own frame loop, builds all 10,241 of the game's graphics pipelines and records about 42,700 draws in a 150-second run, but no draw executes: letting them run hangs the graphics card, and the game gives its display surface nothing to present. Nothing reaches a window.

    Source: project README, measured on an RTX 4090. Entry changed 19:30 UTC, Tue 24 Nov. Last commit 19:13 UTC, Tue 24 Nov.

Time to playable

About 6½ days

Best guess: the afternoon of Tue 1 Dec.

Playable means: At least one project shows 30 minutes or more in the game world under player control, at 20 frames a second or better on some PC, without a crash.

What the estimate rests on

  • The executable surfaced on 23 November. Within about a day, three code bases reported the game world running.
  • The front-runner now shows a lit world with characters, but only direct sunlight works: everything in shadow is black.
  • Speed is the long pole. The best reported figure is about 4 frames a second, and the longest reported session lasted about 13 minutes before the GPU device was lost. Playable needs five times the speed and over twice the session length.
  • Work is shared across projects. victory-gta6 and AnyXboxX build on VIctory, and fixes move between XCL, VIctory and Palmwave in days, not weeks.
  • Takedowns are a real risk. Leonida and at least one community server are already gone.

Method and limits

Playable builds
None exist. Anything offered as a playable download of GTA VI for PC is fake, and fakes have carried malware.
What the projects use
They work from a leaked Xbox Series build. Rockstar has not announced a PC version. This page does not link to the leak or explain how to get or run it.
Sources
Each project's public repository: its README, status files, commits and pull requests. Press reports where a project has no public code. Every row names its source.
Claims
Stages are what each project says about itself, unless the source line says otherwise. This page does not run the code, and most claims are unverified.
Ranking
By stage first, then by how far within that stage the project's own description goes. An equals sign marks a tie.
Who writes it
An AI assistant (Claude) checks the repositories when asked and rewrites the entries. It can be wrong; the source links are there to check it.
Affiliation
None. Not connected to Rockstar Games, Take-Two Interactive, Microsoft or any project listed. Names link to repositories to credit the work.

The seven stages

  1. 1LoadsThe game's executable loads with its imports resolved.
  2. 2Starts upThe game's own start-up code runs: memory, threads, archives.
  3. 3Graphics deviceThe game creates its graphics device and queues on the PC.
  4. 4First framesFrames are presented to a window, even if they are black.
  5. 5Recognisable pictureThe game's own screens can be seen: logos, menus, video or setup pages.
  6. 6In-gameThe game world is loaded and running, with or without a usable picture.
  7. 7Playable30 minutes or more in the world under player control, at 20 frames a second or better, without a crash.
